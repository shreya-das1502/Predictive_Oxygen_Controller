# Phase A audit and ambiguity resolution

- `src/run_experiments.py` selects each whole-record test fold via `evaluation.outer_splits`, generates training-only `grouped_oof` scores (with separately fitted imputation/scaling for each inner model), refits on outer training only, and saves held-out scores. `validation_oof_predictions.csv.gz` has Model, Outer_Test_Record, Record, sample_id, time_s, Label, Score, Threshold. It supports threshold-only nested selection without changing model fits, provided BOTH outer-fold and allowed-record keys are enforced. Full-data demonstration models are not used.
- Existing thresholds optimize 92% timestamp recall, not alarm burden. New thresholds must be stored separately. Threshold selection will finish for both targets/all folds before this experiment reads held-out prediction values for evaluation.
- `reliability_evaluation.current_normal/links/episodes/eligible_events/match_events` defines strict current-normal exposure and real alarm starts, split at negative decisions, >2s gaps, recording boundaries and invalid/intervening-low edges. Events need complete valid raw lead-in and a current-normal opportunity. Left endpoints are included; onset-time alerts are excluded. Chronological earliest unused starts receive at most one event credit. Existing boundary fixes remain unchanged.
- `off_event_alarms` checks all qualifying observed onsets, including sensitivity-excluded ones. Unmatched/redundant starts are not identical to false starts. Active time uses left-held decisions over permitted edges. No exposure across recording boundaries is invented.
- Resolve budget ambiguity before outcomes: local evidence provides no clinically justified budget. Protocol freezes sensitivity budgets 1/5/10 per evaluable hour plus 5% active cap, not a clinical operating point. A low episode count under continuous alerting cannot pass the cap. Primary selection objective uses the unchanged 30s event rule; all four windows are evaluated and shorter-window false rates need not obey the 30s budget.
- Fixed quantile threshold candidates are policy thresholds, not a hyperparameter/model search. Off-event start counts are nonmonotonic with threshold, so each candidate is evaluated explicitly. Scores from different inner refits are not calibrated; train-budget attainment is not a promise on outer refits.
- Four current-low records have no onset/current-normal opportunities; retain zero-exposure rows and undefined rates. Both target training populations remain separate. Patient identity is unverified. Saved-array provenance and existing train-fit tests will be rerun; no new patient claim is possible.
