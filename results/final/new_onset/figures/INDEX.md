# Figure index: new_onset

All figures are generated from this run; source and image hashes are in figure_manifest.json. PNG previews and vector PDFs share each filename stem. Numerical panel tables are saved where relevant. No tuning was performed from these diagnostics.

- [dataset_and_horizon.png](dataset_and_horizon.png) / [PDF](dataset_and_horizon.pdf): Rolling features retain every pulse. Unknown future labels and current-ineligible states are excluded, not labelled negative; positive counts among unknown targets cannot be inferred.
- [missingness_and_clock.png](missingness_and_clock.png) / [PDF](missingness_and_clock.pdf): Missing SpO₂ invalidates future windows. Rounded waveform times are reconstructed only when consistent with the 125Hz row clock; duplicate displayed times are not deleted.
- [pulse_quality_proxies.png](pulse_quality_proxies.png) / [PDF](pulse_quality_proxies.pdf): Intervals are constrained to 0.30–2s. Pulse rate is derived, not independent ground truth. Morphology/dicrotic peaks and clinical signal quality are not validated by these ranges.
- [feature_distributions.png](feature_distributions.png) / [PDF](feature_distributions.pdf): Boxes show median and quartiles; whiskers use the standard 1.5 IQR rule, with outlier markers omitted for readability. Full distributions remain in the dataset. These are exploratory held-out descriptions.
- [feature_correlation.png](feature_correlation.png) / [PDF](feature_correlation.pdf): Pulse rate and interval are mathematically related. Correlation is descriptive, not causation or a basis for post-hoc feature selection.
- [recording_feature_shift.png](recording_feature_shift.png) / [PDF](recording_feature_shift.pdf): Training ranges exclude the plotted recording. This is exploratory shift evidence; it has not been used to change the evaluated models.
- [threshold_and_scores.png](threshold_and_scores.png) / [PDF](threshold_and_scores.pdf): Threshold curves use only grouped OOF training predictions for the prespecified outer record 12. Held-out score distributions are diagnostic; no operating point is chosen from them.

- [latency_distributions.png](latency_distributions.png) / [PDF](latency_distributions.pdf): Warm single-thread empirical distributions; loading is separate. Log axes are explicit. Compute time excludes acquisition/monitor delay and the 30s prediction horizon; local peak confirmation needs another 8ms sample.
- [block_permutation_importance.png](block_permutation_importance.png) / [PDF](block_permutation_importance.pdf): Diagnostic fixed-model refits exclude each tested recording and reproduce its saved scores. Permute 10-pulse blocks, three fixed seeds, each feature separately, average only mixed-class recordings. Correlated features, implausible rate/interval combinations and few recordings limit interpretation. No features or models are selected or retuned; this is not conventional ELM weight importance.
- [model_metrics.png](model_metrics.png) / [PDF](model_metrics.pdf): Pooled and macro metrics have different denominators; undefined recording metrics are excluded from macro means. High recall with low specificity is not a useful detector.
- [ranking_curves.png](ranking_curves.png) / [PDF](ranking_curves.pdf): Pooled curves combine uncalibrated scores from different refits. AP means average precision; ROC can be misleading under class imbalance.
- [confusion_matrices.png](confusion_matrices.png) / [PDF](confusion_matrices.pdf): Counts use the same held-out rows per model, with observed target on rows and predicted decision on columns.
- [recording_performance.png](recording_performance.png) / [PDF](recording_performance.pdf): Negative-only recordings have undefined recall, not zero. All-positive eligible snippets can inflate simple macro summaries.
- [false_alarm_burden.png](false_alarm_burden.png) / [PDF](false_alarm_burden.pdf): Episode starts and FP timestamps measure different burdens. Sustained alerts can have few starts but very poor specificity. Exposure excludes unevaluable periods.
