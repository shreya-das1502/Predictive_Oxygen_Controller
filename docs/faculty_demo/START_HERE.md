Extract `FACULTY_DEMO_PACKAGE.zip` completely. Begin with `guides/01_PRESENTATION_ORDER_AND_CODE_LINES.md`, then `guides/02_FACULTY_SPEAKING_SCRIPT.md`. Open `presentation/Predictive_PID_Oxygen_Control_Presentation.pptx`. Use the five numbered images in `images/` in the prescribed order. The package contains the actual relevant source files and line-numbered text copies, final results tables, reports, presentation-generation prompt, PID scope and template.

The ZIP is a presentation/reference bundle, not a standalone replacement for the full research repository. Source copies retain repository-relative paths under `repository/`. Reproduction needs the full repository, dependencies and original source data; no new training, controller simulation or human annotations were created. No model weights or raw dataset are required for this code walkthrough and they are not duplicated in the ZIP.

Authoritative scope: retrospective prediction completed; PID integration proposed. No PID-control or oxygen-delivery improvement is demonstrated. The uploaded presentation is included unchanged; its citation-number issues are documented in the guide rather than silently edited.

Line numbers are verified against the source snapshot in the package. In VS Code open the file, press Ctrl+G and enter the line number. Do not retrain during the presentation. Use saved results and the existing verification evidence.

`PACKAGE_MANIFEST.json` inside the ZIP records source paths, file hashes and archive inventory. The ZIP has been checked for CRC and content integrity. This package does not alter frozen experiment artifacts.
