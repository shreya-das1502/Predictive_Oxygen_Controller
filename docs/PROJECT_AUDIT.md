# Project audit and implementation plan

## Inspected state
There are 30 paired raw CSV recordings (01–30), an eight-column prepared `results/elm_dataset.csv`, 26 recording groups, and 17,089 rows with 466 positives. Historical counts for 07/12/17/26/29/30 exactly match 45/50/47/216/11/97. No dependency manifest or tests existed. `model.py`, `controller.py`, and `preprocessing.py` were empty. README contained only the project title. Git already contained a modified `elm_experiment.py` and many untracked experiment scripts/results; these are preserved. The complete import/risk inventory is `legacy_inventory.json`.

## Architecture and data flow before repair
`main.py` plots one recording. `features.py` processes record 01 at import time, then `labeling.py` labels it at import time. `elm_experiment.py` independently extracts all raw records and creates the prepared dataset. Numerous experiment scripts independently implement ELM, features, splits, threshold rules, and output names. `compare_models.py`, conventional and threshold scripts use random row splits. `advanced_experiment.py` removes 17/29, uses only 12 for validation and 07/30 for testing. Recording-aware v2 uses one positive and one negative validation recording, not representative grouped validation.

## Verified schema and source
Prepared columns: Record, time_s, PPG_Amplitude, Pulse_Interval_s, Pulse_Rate_BPM, Amplitude_Slope, spo2, Label. Raw waveform columns: Time [s], RESP, PLETH, V, AVR, II. Numerics: Time [s], HR, PULSE, RESP, SpO2. Each waveform has 60,001 samples, 125 Hz, 0–480 s; each numeric file has 481 rows at 1 Hz. Record 23 numeric times are -1–479 s; preserve the provided common seconds coordinate rather than independently rebasing the two files. Source monitor latency and timestamp accuracy cannot be verified from CSV alone.

The official [PhysioNet description](https://physionet.org/content/bidmc/1.0.0/) describes 53 eight-minute recordings, waveform sampling at 125 Hz and numerics at 1 Hz. Only the local 30 recordings are evaluated. Numeric SpO2 is missing in records 01 (13), 05 (6), 19 (102), 25 (1). Raw PPG has no missing values.

## Labels and known bugs
The all-record builder uses strictly future `(t,t+30]` numeric observations and <=94%, but removes current SpO2 <=94 and accepts incomplete windows at the end. Thus records 04/08/09/22 disappear and 17/29 become artificially short: raw recordings are all eight minutes. The single-record feature script assigns next-pulse intervals/troughs to the earlier peak, adding lookahead. All waveform builders use `sosfiltfilt`; the all-record peak prominence also uses the complete waveform standard deviation. These are future-information leakage. Legacy label verification repeats incomplete-window behavior, so agreement is not proof of correctness. `inspect_events.py` has a pasted shell command on line 66 causing SyntaxError. Advanced rolling initialization drops five rows per record; v2 zeros initial rolling features but still drops invalid base rows without a stage audit. Undefined recalls are converted to zero; simple macro recall then mixes negative-only recordings into the average. Legacy latency times scaled model inputs and omits preprocessing and streaming features.

## Poor performance: hypotheses to check
Poor historical results are consistent with weak pulse-only features, recording distribution shift, sparse transition events, and unrepresentative threshold validation. Leakage and a selected target population invalidate claims based on those results. No causal explanation or ELM advantage will be assumed before the matched evaluation.

## Final architecture and execution plan
1. Implement reusable causal SOS waveform preprocessing, confirmed local pulse detection, shared bounded rolling state, complete-horizon labels, and explicit validation/stage accounting.
2. Independently audit legacy labels and regenerate the primary prepared dataset from all raw records without current-SpO2 selection. Keep source/current/future SpO2 only as ground truth/diagnostics, never model inputs.
3. Fix model configurations before running: weighted 50-node ridge ELM, balanced regularized logistic, Gaussian naive Bayes statistical baseline, shallow decision tree; identical ten pulse features and training-only imputation/scaling.
4. Leave one recording out; inside each outer training set use 3-fold GroupKFold OOF scores from all training rows for the largest threshold meeting 92% validation recall. No hyperparameter search or outer-label threshold access.
5. Save all held-out rows, pooled and macro metrics, raw-onset event matching, severe-event subset, diagnostics, and manifest. Fit demonstration artifacts on all data using grouped OOF thresholds, explicitly distinct from held-out evaluation.
6. Test causal prefix equivalence, streaming/offline parity, labels, splits, training-only transformations, ELM stability/persistence, inference contract, and timing. Benchmark warm steady-state inference separately from model loading.
7. Generate README and measured evaluation/latency reports.

## File decisions
Keep all user-modified/untracked experiments and historical results in place; they are legacy, not authoritative results. Preserve original features, labeling and latency scripts in `archive/legacy_src/` before replacing those entry points. Fill empty core modules. Add one runner and evaluation/data/report modules. Do not move legacy ELM scripts because active legacy imports depend on them. Authoritative outputs are under `results/validated/`, preventing overwrite of user results. No raw files are edited or added to Git. No automatic data downloads.

## Execution findings
Raw timestamps are rounded to 0.01s after 100s, producing 9,500 duplicate displayed waveform times per record. Uniform 125Hz row-clock timestamps agree with every exported time within 0.004s; acquisition clock reconstruction retains all samples. Actual irregular/missing clocks are rejected, not interpolated. Independent legacy-label masks verified 15,706 fully observable rows with zero disagreements, but 1,096 rows have incomplete future horizons and 287 cross missing future SpO2. These 1,383 invalid targets were treated as usable historically. An incomplete target is never declared negative. The causal rebuild has 20,157 evaluable rows, 4,587 positives, 30 groups, six all-positive groups, and ten positive-containing groups. None are short raw recordings. Initial rolling feature generation removes zero rows. Unknown-positive removal counts are NaN in the stage audit because those target values do not exist.

Model training/validation has completed for 120 outer/model combinations using fixed configurations and three grouped inner folds each. No slow grid search was reintroduced. Old scripts/results remain historical; authoritative files live in `results/validated/`. Original modified `elm_experiment.py` remains untouched by this task. The syntax error in legacy `inspect_events.py` was repaired by commenting its pasted invocation. Generated large prepared/pulse/OOF files and binary artifacts remain locally available but are ignored in Git; compact final metrics, plots and metadata are not ignored.
